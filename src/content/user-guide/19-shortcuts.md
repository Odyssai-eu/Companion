# Keyboard shortcuts

The full keyboard map. macOS uses ⌘; Windows / Linux uses Ctrl in the same slot.

## Chat input

| Action | macOS | Windows / Linux |
|---|---|---|
| Send message | ⏎ | Enter |
| Newline in input | ⇧⏎ | Shift+Enter |
| Stop streaming | Esc | Esc |
| Push-to-talk (anywhere outside inputs) | hold Space | hold Space |
| Send and chain new chat | ⌘⏎ | Ctrl+Enter |

## Conversations

| Action | macOS | Windows / Linux |
|---|---|---|
| New conversation | ⌘N | Ctrl+N |
| Focus search | ⌘K | Ctrl+K |
| Edit user message (resend) | ⌘⏎ in edit mode | Ctrl+Enter in edit mode |
| Cancel edit | Esc | Esc |
| Edit user message (start) | double-click message | double-click message |

## Settings

| Action | macOS | Windows / Linux |
|---|---|---|
| Open settings | ⌘, | Ctrl+, |
| Close mobile sidebar | Esc or tap backdrop | Esc or tap backdrop |
| Cycle settings tabs | (none today) | (none today) |

## Voice

| Action | macOS | Windows / Linux |
|---|---|---|
| Toggle voice mode | ⌘⇧V | Ctrl+Shift+V |
| Push-to-talk | hold Space (outside inputs) | hold Space |
| Stop TTS playback | Esc | Esc |

## Universal

| Action | Key |
|---|---|
| Close any overlay / cancel any action | Esc |
| Submit any primary CTA | ⏎ / Enter |

## Tips

- **Push-to-talk works anywhere** except inside text inputs — the Space key still types a space when you're typing.
- **Esc is universal**: cancels edits, stops streams, closes overlays. If you're confused, hit Esc.
- **⌘K focuses search AND opens the picker** if it's collapsed — same key, two states.
- **⌘N** creates a new chat **in the active project** when you're inside one (matches the sidebar Chat button).

## Customising

There's no key-rebinder UI today. If a shortcut clashes with a browser extension you can't live without:

- **1Password / Bitwarden** — they sometimes grab ⌘\\ or ⌘.;
- **Raindrop, Pocket** — they hook ⌘K on certain sites.

Workaround: disable the extension on your Companion host specifically (most extensions support per-domain disable).

If a fundamental shortcut (Send, New chat, Search) clashes for you on every browser extension you have: tell us, the layer is small enough that we can rework it.
